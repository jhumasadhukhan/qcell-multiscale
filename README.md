# QCell — a quantum-to-cellular multiscale model of an intracellular biosensor

Reference implementation for *Polymer accumulation biases the intracellular
biosensor used to control it* (J. Sadhukhan).

A genetically encoded FRET biosensor is used to read an intracellular
metabolite while a fermentation runs. This code couples the photophysics that
produce the sensor's signal to the fermentation that the signal is used to
control, and shows that the two cannot be separated: **the polymer the process
accumulates scatters the donor and acceptor bands unequally, so the ratiometric
readout drifts in one direction as the process succeeds.**

The headline numbers, all reproducible from this repository:

| | |
|---|---|
| Error in inferred 2-oxoglutarate from a raw ratio | **+29 %** |
| Polymer titre lost to that error | **a fifth** |
| Error after the multiscale correction | **below 10⁻¹³ %** |
| Extra hardware required for the correction | **none** |

## Quick start

```bash
git clone https://github.com/jhumasadhukhan/qcell-multiscale.git
cd qcell-multiscale
pip install -r requirements.txt

python tests/test_qcell.py     # 18 invariants, ~20 s
./reproduce.sh --quick         # tests + worked examples, ~30 s
./reproduce.sh                 # full results, figures and paper check, ~45 min
```

`reproduce.sh` writes `results/results.json` and `figures/fig1…fig5.png`, then
runs `paper/verify_paper.py`, which re-checks all 28 numbers quoted in the
paper against the results just computed and exits non-zero if any has moved.
Nothing else is needed: there are no data files to download, because every
number in the paper is generated by this code.

To explore the model without installing anything, open
[`web/qcell_lab.html`](web/qcell_lab.html) in a browser. It is a self-contained
JavaScript port of the same equations, written independently and cross-checked
against the Python to three significant figures on every reported scenario.

## What the model is

Two layers, differing in timescale by twelve orders of magnitude.

**The quantum layer** (femtoseconds to nanoseconds) computes what the
instrument records, from first principles rather than from a calibration curve:
point-dipole Coulomb coupling, the golden-rule transfer rate calibrated against
the Förster radius, a Haken–Strobl coherence correction, the orientation factor
under partial rotational averaging, the refractive index of a granule-filled
cytoplasm by Lorentz–Lorenz mixing, and band-resolved optical transport out
through a turbid suspension.

**The cellular layer** (minutes to hours) is a fed-batch PHA fermentation on
bioelectrochemically generated formate, with Haldane kinetics on both carbon and
nitrogen, an explicit 2-oxoglutarate node, an active/inactive biomass split and
a storage ceiling.

**The coupling is bidirectional.** Nine variables cross the interface. The one
that makes it irreducible is polymer concentration: it sets the excess
scattering, and no non-destructive bulk measurement separates polymer from
residual biomass, so it has to come from the cellular model. Because the
timescale ratio is ~10⁻¹², Tikhonov's theorem applies and the fast layer enters
as an algebraic constraint rather than as a stiff ODE — which is what makes the
whole thing run on a laptop.

```
qcell_model.py
├─ QuantumParams / CellParams / BESParams   parameter objects
├─ quantum_map()         cellular state  ->  ratiometric observable
├─ invert_quantum_map()  observable      ->  inferred metabolite
│                        correction = "full" | "od_only" | "none"
├─ rhs(), simulate()     the coupled system
└─ Controller            clock | closed_raw | closed_od | closed_multiscale
```

## What the tests guarantee

`tests/test_qcell.py` is not a smoke test. It checks the identities and
invariants that the published claims depend on:

- the golden-rule rate and the Förster rate agree at R₀ (the calibration that
  makes the quantum layer self-consistent)
- E = 1/(1+(R/R₀)⁶) *follows from* the rate expression rather than being imposed
- κ²_eff always lies between its static value and the isotropic 2/3, and moves
  towards the static value as crowding increases
- **T_A/T_D > 1 for every biomass, polymer loading and scattering exponent** —
  the paper's central structural claim, which follows from λ_D < λ_A alone
- the full inverse map round-trips to better than 10⁻⁹ across the operating
  domain, while the density-only correction provably does not
- a raw ratio over-reads the metabolite and can never under-read it
- states stay physical through a simulation (no negative concentrations, no
  more polymer than biomass)

Two are regression tests, named as such in the file, for errors found and
fixed during the work. They are described below, because a reader is entitled
to know what changed.

## Two corrections recorded in the open

**The inverse map.** The detection model adds the dark offset *after* optical
attenuation, so the inverse cannot undo transport by pre-scaling the observed
ratio by T_D/T_A — that shortcut is exact only for a zero dark offset. It
biased recovered 2-oxoglutarate by −0.5 % at low turbidity and by −9.8 % at
C_X = 16 g L⁻¹, worst exactly where the correction matters most. The
transmissions now enter the linear solve for (1−E) directly, and the full
correction is exact to machine precision. Guarded by
`test_inverse_map_is_exact`.

**The packing fraction.** An earlier version used φ_max = 0.68. Random close
packing of monodisperse spheres is ≈0.64; 0.68 falls between random and
crystalline close packing, where no random monodisperse packing sits
(Torquato, Truskett & Debenedetti, *Phys. Rev. Lett.* **84**, 2064, 2000).
Guarded by `test_packing_fraction_is_random_close_packing`.

## Parameter provenance — read this before quoting a number

Of the 84 parameters, **41 are literature values, 26 are engineering estimates
with no primary source, 12 are derived and one is fitted.** Supplementary
Tables 4–6 of the paper give every one with its provenance code and source.

An independent audit of the literature values found **four that disagree with
the sources they were taken from**, including the scattering exponent and the
refractive indices that set the size of the effect. These are flagged A† and L‡
in the tables, and Supplementary Note 3.5 reports the audit in full.

**The conclusion survives every one of those corrections** — the uncorrected
bias ranges from +6 % to +20 % across them and never changes sign, because the
sign follows from the donor band lying to the blue of the acceptor band and no
parameter can reverse it. But the *magnitude* is not established for any
particular fermentation. Treat this work as establishing a mechanism, a sign
and a scaling law, together with a correction that is exact once the parameters
are known — not as a validated prediction of any specific process.

The cheapest way to pin down the magnitude is to measure the scattering
exponent of the actual culture: a spectrometer and a dilution series.

## What is deliberately not here

The scripts that typeset the manuscript and supplementary file — citation
numbering, Word conversion, table layout — are not included. They produce the
paper, not the results, and shipping a half-current copy of them would be worse
than shipping none. Everything that produces a *number* is here.

`paper/parameter_table.py` dumps the parameter values from the model objects,
which is the verifiable half of the claim in Supplementary Note 3 that the
tables are generated rather than retyped. The provenance codes and literature
sources are editorial judgements that cannot be derived from code; they live in
Supplementary Tables 4–6 and Supplementary Note 3.5.

## Requirements

Python 3.9+, NumPy and Matplotlib. Nothing else — the integrator is a
hand-rolled RK4 in `qcell_model.py`, so there is no SciPy dependency and no
version-pinning fragility.
